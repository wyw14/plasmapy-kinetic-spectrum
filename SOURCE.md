# Source

Application extension built on PlasmaPy 2026.2.0 (BSD 3-Clause), commit fca3bc8a97a19b91a6c7b105b450cea2c2f251a9.
Upstream: https://github.com/PlasmaPy/PlasmaPy

The Maxwellian populations are synthetic. The implementation uses PlasmaPy's Landau plasma dispersion function and adds finite-window mode completeness, residues, and the specified pole response.
